# Flownix identity

Original mark: three time-separated observations converge into a single inspectable flow. The vertical stroke anchors the mark as an open F. No coin, shield, hexagon, Binance motif or proprietary template asset is used. This is independent research software and must never imply Binance endorsement.

Primary identity: horizontal logo on graphite; compact version for narrow spaces; mark for favicon/app icon. Light/dark and wordmark-only SVG variants live in apps/web/public/brand. PNG exports are generated from the vector originals by scripts/export-brand.mjs. Social graphic contains no private data.

Clear space: at least one-quarter mark width. Minimum mark size: 20px; use icon rather than wordmark below 120px horizontal width. Preserve paths and proportions. Do not stretch, gradient-fill, animate continuously or use state colors to imply returns.

Palette: graphite #101316, raised graphite #171b20, off-white #edf0f3, observation blue #a7cae2. Semantic jade #8dcbb3 means a positive observed change, amber #e1be82 means caution/incomplete, rose #e39b9d means negative/risk; no color predicts an outcome. Light theme uses explicit accessible alternatives. Actual tokens are in globals.css.

UI uses the operating system sans stack for a familiar high-density workstation. Vector wordmarks use DejaVu Sans (freely redistributable Bitstream Vera-derived font), converted to outlines for release exports when available. No remote font service or unlicensed font binary is required. Source SVG text remains editable; generated PNGs provide portable rendering. Mark geometry is original project artwork. Trademark clearance has not been performed.

Motion: 140ms color/opacity feedback; no page entrance choreography. Reduced-motion removes transitions. Charts never animate data into misleading intermediate values.
