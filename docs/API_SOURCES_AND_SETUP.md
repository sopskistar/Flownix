Historical market candles currently reach roughly 187 days for some symbols; other symbols have shorter returned history. They became locally available when fetched, not at historical signal time. Address balances cover sampled blocks only, not 180-day retention or a complete holder census. No authenticated centralized-exchange account activity is accessible.

Run `pnpm providers:production`, `pnpm collection:status`, `pnpm worker:diagnostics` and the live-gate commands documented in TESTING.md. Provider fixtures in CI are clearly dated/synthetic; they do not populate production. Source response hashes and request audit failures remain stored. Official terms and geographic restrictions still apply; no proxy or geographic bypass is configured.
