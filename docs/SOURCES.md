## Design references

Read accessible DEX Screener, DefiLlama and GeckoTerminal pages; studied identity columns, dense table hierarchy and pool-specific attribution. Consulted [Framer Marketplace](https://www.framer.com/marketplace/templates/) and [Sightline Lite](https://www.framer.com/marketplace/templates/sightline-lite/) (free preview, limited license) for responsive filtering/pagination only. No commercial template, fabricated metrics or assets were copied. Installed skill references and the shared creative-studio Framer reference were inspected. UI UX Pro Max returned an off-task marketing pattern; its contact-sales/hero recommendation was rejected in favor of the explicit research-terminal brief.
